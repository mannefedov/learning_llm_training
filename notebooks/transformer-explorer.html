What each dimension changes

DimensionEffect in this GPT
Context TPositions visible in one sequence. Dense attention scores grow as T². Learned position tables add T × d weights.
Width dChannels carried at every token. Hidden matrix parameters grow roughly as d². Each feed-forward network expands to 4d.
Heads HPartitions d into H parallel attention heads. At fixed d, projection parameter counts stay the same.
Layers LSequential processing depth. Adds a full set of attention, feed-forward and normalization weights per layer.
Vocabulary VInput token rows and output classes. Independent input and output matrices each contain V × d weights.
Batch BSequences processed together. Changes activation memory and targets per update, while parameter counts stay the same.

Shapes include the microbatch dimension B. Counts include biases and LayerNorm parameters. Attention score memory is B × H × T × T in FP32 for one layer, excluding other activations and gradients. Our reference attention materializes this tensor. Fused kernels can avoid storing the full score matrix. Gradient accumulation increases targets per optimizer update without changing B here.

RoPE rotates Q and K using a fixed frequency base of 10,000 and adds no trainable position parameters. The diagram shows causal full attention and the 4× GELU feed-forward network used in our code. Values are computed locally from these dimensions.
